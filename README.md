## 🌟 Sobre o Jogo

Em **Chroma Hunt: Camuflados**, os objetos não estão simplesmente escondidos: eles **mimetizaram cores, contornos e texturas** do próprio ambiente, desafiando a percepção e a lógica do jogador!

O jogo combina:
- **Cenários Ricos e Coloridos**: Arte procedural e vetorial de alta definição com zoom focalizado e arraste livre de câmera (pan).
- **Charadas Dedutivas**: Cada item possui uma pista misteriosa que estimula o raciocínio dedutivo antes da busca.
- **Lanterna UV (Luz Negra)**: Ferramenta tática que revela silhuetas fluorescentes por tempo limitado enquanto consome bateria.
- **Cenário Interativo**: Elementos que podem ser movidos ou acionados (almofadas, caixas flutuantes, escudos de energia) para revelar itens ocultos.
- **Mecânica Anti-Spam**: Penalidade de sobrecarga para cliques aleatórios sem reflexão, valorizando a observação consciente.
- **Áudio Procedural**: Sintetizador via Web Audio API para efeitos sonoros e trilha ambiente sem dependências externas.

## 🗺️ Fases Disponíveis

1. **O Quarto do Criador Cósmico**: Mundo gamer e tech den cheio de luzes RGB, monitores e colecionáveis.
2. **Beco Noturno Cyberpunk**: Rua iluminada com lanternas neon, barraca de lamen, grafites e cabos aéreos.
3. **Laboratório de Ilusões Óticas**: Feixes de laser quânticos, prismas, perspectiva axonométrica e cilindros de plasma.

## 🎯 Controles & Teclas de Atalho

| Ação | Controle |
| :--- | :--- |
| **Investigar / Clicar** | Botão Esquerdo do Mouse ou Toque |
| **Mover Cenário (Pan)** | Clicar e arrastar com o mouse ou deslizar o dedo |
| **Aproximar / Afastar (Zoom)** | Roda do mouse (Scroll) ou botões `+` e `-` |
| **Resetar Câmera** | Botão `1x` ou tecla `Espaço` / `R` |
| **Ativar Luz Negra UV** | Botão na tela ou teclas `Z` / `U` |
| **Ver Charada / Dica** | Clique no card do objeto na barra inferior |

## 🚀 Como Executar Localmente

Não requer instalação de dependências ou servidores complexos!

1. Clone o repositório:
   ```bash
   git clone <URL_DO_SEU_REPOSITORIO>
   cd camuflados-game
   ```
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Edge, Firefox, Safari).

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Semântica e estrutura de HUD moderna.
- **CSS3**: Glassmorphism, gradientes neon, animações e responsividade.
- **Vanilla JavaScript**: Motor Canvas 2D customizado, detecção de colisões pixel-accurate e manipulação de estado.
- **Web Audio API**: Sintetização sonora em tempo real sem arquivos de áudio externos.
